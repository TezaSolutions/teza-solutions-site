Alternatives aux plateformes de livraison — ce qui existe vraiment

Uber Eats, DoorDash, SkipTheDishes : les plateformes prennent entre 15 % et 30 % par commande. Sur une commande de 40 $, vous récupérez au mieux 34 $, au pire 28 $.

Beaucoup de restaurateurs cherchent à s'en sortir. Moins cherchent à savoir ce qui les attend de l'autre côté. Cet article fait le tour des vraies options — sans vous vendre une solution miracle.

1. Le site web avec module de commande en ligne

Vous avez un site, ou vous en commandez un. Vous ajoutez un module de commande intégré — Square, Toast, ou un outil similaire.

Ce que ça donne en pratique : le client va sur votre site, choisit ses plats, paie. Vous encaissez sans intermédiaire, ou avec une commission très faible (1 % à 3 % selon la plateforme).

Les vrais avantages :

  • Vous possédez les données clients.
  • Ça alimente votre référencement Google si bien configuré.
  • Coût mensuel prévisible, souvent entre 50 $ et 150 $/mois selon le service.

Les vraies limites :

  • Le client doit vous trouver, aller sur votre site, créer un compte ou entrer ses informations à chaque commande.
  • La friction est réelle. Moins de visibilité qu'une plateforme.
  • Si votre site n'est pas rapide et mobile, le taux d'abandon est élevé.

À considérer si vous avez déjà une base de clients fidèles qui vous cherchent activement en ligne.

2. L'application mobile à votre marque

Une app avec votre logo, votre menu, votre programme de fidélité. Le client télécharge, commande, repaye.

Les vrais avantages :

  • Image de marque forte.
  • Programme de fidélité intégré possible.
  • Zéro commission sur les commandes.

Les vraies limites :

  • Développement : entre 10 000 $ et 50 000 $ pour une app fonctionnelle, selon la complexité.
  • Maintenance continue, mises à jour iOS/Android, bugs à corriger.
  • La friction est maximale : demander à un client de télécharger une app pour commander une poutine, c'est beaucoup.
  • Le taux d'installation est faible pour les restaurants indépendants.

Option réaliste pour les chaînes avec plusieurs succursales. Difficile à justifier pour un restaurant unique.

3. Le QR code en salle

Vous placez un QR code sur les tables. Le client scanne, consulte le menu, commande depuis son téléphone.

Les vrais avantages :

  • Très simple à mettre en place.
  • Réduit les erreurs de commande en salle.
  • Coût quasi nul si vous utilisez un outil de base.

Les vraies limites :

  • Ce n'est pas une solution de livraison. C'est une solution de commande sur place.
  • Pour les commandes à emporter ou à livrer, ça ne règle rien.
  • Le client doit être physiquement dans votre établissement.

Utile pour améliorer l'expérience en salle. Ne remplace pas une plateforme de livraison.

4. La commande par WhatsApp avec paiement intégré

Le client vous envoie un message WhatsApp. Un agent IA répond, prend la commande, confirme les détails, déclenche le paiement via Stripe. Vous encaissez 100 % du montant.

Les vrais avantages :

  • Zéro friction côté client : WhatsApp est déjà installé sur la quasi-totalité des téléphones.
  • Zéro commission sur la commande.
  • Le paiement se fait dans la conversation, sans redirection vers un autre site.
  • Pas de compte à créer, pas d'app à télécharger.

Les vraies limites :

  • Ça demande une mise en place initiale : connexion WhatsApp Business, configuration de l'agent IA, intégration Stripe.
  • Ce n'est pas une solution plug-and-play à configurer seul en 10 minutes.
  • Si votre clientèle utilise peu WhatsApp, l'adoption sera plus lente.

C'est le modèle qu'on a développé chez Teza Solutions. L'agent répond 24 h/24, gère les questions courantes, confirme chaque commande. Le restaurant surveille, mais n'intervient pas manuellement à chaque échange.

Ce que ça veut dire pour vous

Il n'y a pas une seule bonne réponse. Ça dépend de votre type de clientèle, de votre volume de commandes, et de ce que vous êtes prêt à mettre en place.

  • Le site web convient si vous voulez investir dans votre présence en ligne à long terme.
  • L'app mobile convient si vous gérez plusieurs succursales et avez le budget.
  • Le QR code convient pour améliorer l'expérience en salle — pas pour la livraison.
  • WhatsApp convient si vous cherchez la solution à friction zéro, sans commission, opérationnelle rapidement.

Ce qui est certain : continuer à donner 15 % à 30 % par commande est un choix. Pas une obligation.
